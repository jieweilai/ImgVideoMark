# ImageVideoMark

本仓库包含图像/视频水印相关的代码与工具。

- **`inference`**: 本仓库中的 `inference` 文件夹的源码来源于开源项目：
	https://github.com/gzlIU-nOthOrsE/Watermarking-One-for-All_cvpr.25

- **`func`**: 基于 `inference` 开发的功能模块，包含水印嵌入（embed）与验证（verify）等便捷接口和示例。

具体使用方法与示例请参见： [func/README.md](func/README.md)

如果需要英文版说明、许可证信息或示例脚本，我可以继续补充。
